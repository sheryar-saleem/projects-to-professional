# DocMind Frontend

Next.js 16 / React 19 / TypeScript / Tailwind CSS v4 frontend for DocMind.

## Run

```powershell
cd frontend
npm install
npm run dev
```

Optional environment variable:

```env
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

The UI includes persistent conversation history, document management, real backend health status, an admin metrics view, settings, markdown answer rendering, and an Obsidian & Emerald visual system.
